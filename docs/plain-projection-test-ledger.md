# Plain projection test ledger

This ledger covers the risks of the closed scalar projection detector. It is not a claim of exhaustive proof for arbitrary React or Legend programs. Analyzer contracts are exercised through `analyzeLegendPractices`; runtime contracts use the installed React 19.2.8 and Legend State 3.0.0-beta.48 with real jsdom roots and `act`, without sleeps or mocked subscriptions.

| Risk                             | Evidence and trigger                                                                                             | Protected contract / plausible defect                                                                | Independent oracle and test level                                                                                                                                                  | Status                                                            |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| P1: hidden tracking              | A comparison can call a helper reading another observable                                                        | A migration must not add triggers; moving the helper into tracking would update previously stable UI | Analyzer rejects helper/getter/throwing-helper shapes; runtime changes only the hidden source and observes original `true` versus unsafe `false`, in both modes                    | Covered                                                           |
| P1: lifecycle and snapshots      | Raw or projected values may enter effects, callback dependencies, or event closures                              | Suppressing a render must not suppress required effect execution or retain a stale event value       | Analyzer rejects event/effect consumers; runtime changes a raw ID with unchanged boolean, then checks one effect refresh and click snapshots `[1, 0]` for original/unsafe versions | Covered                                                           |
| P1: parameter work               | Defaults, rest, and computed destructuring run before the body                                                   | Body-only purity would skip parameter calls or getter work                                           | Analyzer controls for defaulted comparison prop, extra defaulted prop, parameter default, rest, computed key; removing the guard makes tests fail                                  | Covered                                                           |
| P1: ownership                    | Observer, memo, aliases, exports, async functions, and direct calls can change ownership                         | No subscription relocation claim across an unproven owner boundary                                   | Private JSX owner positive; wrappers/reexports/aliases/async rejected; real observer control records separate subscriptions and confirms no detector authorization                 | Covered                                                           |
| P2: equality benefit             | Boolean and finite-domain inputs need not collapse distinct updates                                              | Avoid treating primitive output or an injective suffix as proof of render savings                    | String/number strict equality and inequality accepted; boolean/literal-union/array/nullable/promise/unknown sources, loose comparisons, injective strings rejected                 | Covered within subset                                             |
| P1: live prop and mount identity | Inline selector closes over a prop that can change without observable mutation                                   | Capturing the initial prop or remounting rows would change selection or lose state                   | 500 keyed rows, source change, prop-only update preserving DOM identity, second source change, and unmount; normal/StrictMode assertions                                           | Covered                                                           |
| P2: exact hook instruction       | Imported `useValue` may have an alias, while that spelling denotes another function                              | The recommended code must invoke the proven import                                                   | Alias and unrelated-module-binding regression asserts replacement; hardcoding `useValue` makes it fail                                                                             | Covered                                                           |
| P1: provenance and shadowing     | Source/getter/type assertions or shadowed bindings can masquerade as scalar reads                                | Do not subscribe to an unproven source or invoke an unrelated hook                                   | Imported factory/root proof plus negative shadow/property path/helper initializer/assertion/untyped/optional/unknown prop controls                                                 | Covered within subset                                             |
| P2: version/export gates         | Legend v2 auto tracking and missing hook exports alter available APIs                                            | Do not recommend unavailable or differently owned subscriptions                                      | v2 and known missing export reject; tested beta alias accepts; unknown version/export follows the existing permissive registry convention                                          | Covered gates; unknown runtime compatibility remains unverified   |
| P1: JSX work and identity        | Key/ref, spread, event props, component children, namespace tags, and custom runtime pragmas alter host behavior | Suppressed renders must affect only inert React host output                                          | Analyzer negative controls for key/ref/spreads/custom children/intrinsic owner name/namespace/explicit alternate factory                                                           | Covered syntax; project-wide custom JSX config is not represented |
| P2: cost claim                   | Selector work remains linear even if renders shrink                                                              | Do not claim constant-time updates or native speedup                                                 | 500 → 2 normal renders with 502 selectors; 1000 → 4 StrictMode renders with 504 selectors; excludes mount work                                                                     | Covered for executed scenario, not wall-clock/native timing       |
| P2: corpus precision             | A new action must not silently relabel uncertain real applications                                               | Preserve pins, source-audited labels, and known failures                                             | Seven-app before/after complete records identical; Playlist callback case is non-enforced research; TrackItem selectors remain controls                                            | Covered at pins                                                   |

Counterfactual evidence is saved in `mutations.log` with the validation artifacts. Mutations were applied only to the compiled detector, each targeted test exited nonzero, and the exact original compiled contents were restored before the final quality build. Runtime unsafe versions are deliberate negative controls, never recommended migrations.

Residual scope: same-file module scalar observables, named imports, strict left-operand equality/inequality, private function components, simple typed destructured props, and three-statement inert owners only. Imported source summaries, observer migrations, exported components, finite-domain cardinality proofs, arbitrary computations, helper purity summaries, native hosts, concurrent renderer scheduling beyond the exercised React DOM/StrictMode contract, and project-wide alternate JSX factories are not established here. There are no timers, network writes, persistence, authorization, or multi-step mutations in this change; corresponding scenario-catalog families are inapplicable.
